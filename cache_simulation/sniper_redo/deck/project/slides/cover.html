Can a better CPU cache speed up kraken2?

What we simulated, what we found, and how to read each graph

Sniper simulation of the Luna server, 190 runs

Plan of the talk: what kraken2 does and why memory matters, what a cache and a prefetcher are, how the experiment was set up, then four results, each with how to read the graph, what we found and why. Last slide: what we can and cannot claim. All numbers are simulated time from Sniper, not measurements on the real machine.
