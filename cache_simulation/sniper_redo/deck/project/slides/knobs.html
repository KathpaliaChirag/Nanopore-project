Four things a cache designer can change

Associativity

How many places a block of memory may sit in the cache. 1-way: one place, so two blocks that share it keep evicting each other. 4-way: four places to choose from.

Replacement policy

Which block is thrown out when the places are full. LRU: the one unused longest. SRRIP, NRU, NMRU, PLRU: cheaper approximations. Random: pick any.

Size

How many bytes the level holds. We tried the LLC from half to 4 times its size, and the L2 at 1, 2 and 4 MB.

Prefetching

Guess what will be needed next and fetch it before it is asked for. The depth is how many blocks ahead it fetches.

The first three change how well the cache keeps useful data. Prefetching is different: it tries to bring data in before the program asks, which hides the wait. Everything we tested is one of these four.
