L1 cache

L2 cache

2 MB

LLC (last level)

Main memory

8 GB or 16 GB

Found in a level: a hit, fast. Not found: a miss, so ask the next level, which is bigger and slower.

Sizes are Luna's, as modelled in Sniper. Bars are not to scale. In the model, one main-memory access costs a fixed 45 ns.

L1 is closest to the core, then L2, then the last-level cache (LLC), which the cores share. The whole kraken2 database is the orange bar: it is thousands of times bigger than the caches above it, so a lookup into it usually misses every cache level.
