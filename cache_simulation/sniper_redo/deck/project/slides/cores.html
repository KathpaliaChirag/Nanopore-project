More cores, a bigger gain

How to read it

Height is the time saved by L1 and L2 prefetchers together. Grey is a control: an LLC change that did nothing in every other test.

What we found

At 16 cores the prefetchers save 18.0% on the 8 GB database and 24.9% on 16 GB.

Why trust the gap

The control stays within 0.9% at every core count, so the gap above it is not noise.

Not explained yet

We have not tested why more cores gain more. See the next slide.

Each percentage compares the same core count, database and 50-read input with and without the prefetchers. Base is Sniper's default hardware, which has no prefetcher at all, so the gain on the real machine, whose CPU already has prefetchers, would be smaller. 8 GB at 8 cores: 8,880.7 to 7,265.8 microseconds. The 16 GB database was not run at 4 cores. The 12, 32 and 64 core runs were not done.
