The lookups jump around, so there is no pattern and nothing to fetch ahead.

Depth: how many blocks ahead it fetches. We tried 1, 2, 4, 8 and 16.

This is the reason we expected a prefetcher to help only the parts of kraken2 that read memory in order, such as the input file, the scan along a read and start-up work, and not the random hash-table lookups themselves. That expectation is our reading of the mechanism; we did not measure the two parts separately.
