Cache design changes: no measurable speed-up

How to read it

Each dot is one simulated run. 0 means the same speed as the unmodified cache. Right of 0 is slower.

What we found

All 14 LLC variants are within 0.3% of base. A 4-way LLC: +0.04%. Only a half-size L2 (+2.4%) and a random-replacement L2 (+1.15%) are clearly worse.

Why

A 50-read run touches each cache line about once, so a better cache has nothing to reuse. The LLC served 0.00% of loads.

8 GB database, 1 core, 50 reads. Generated by figures/plot_figs.py from data/hw_results_all.csv. This is a limit of the experiment: the full job has 1.87 million reads and would reuse data far more, so this does not prove that cache design cannot matter for the real workload.
